## 📋 Sobre

Estudos do runtime Node: servidor HTTP puro, EventEmitter, streams e padrões de backend sem framework.

## 📂 Conteúdo

- `server.js` — HTTP server sem Express
- `events.js` — EventEmitter customizado
- `streams.js` — transform streams
- `worker.js` — background processing

## 🚀 Quick start

```bash
node server.js   # http://localhost:3000
```
